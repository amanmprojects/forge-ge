FORGE

Five games built on Forge, a C++20 2D engine on SDL3 and OpenGL. Each page runs the same C++ source as the desktop build, compiled to WebAssembly and drawn with WebGL2. The clips are the games' own autopilots, rendered frame by frame with --record.

BREAKOUT

Atari-style Breakout with armored bricks, paddle spin, particle bursts and screen shake. Every sound is synthesized at startup; there are no asset files.

SNAKE

Classic Snake that glides between cells and speeds up as you eat. Every fifth apple drops a golden bonus that expires if you dawdle.

CHESS

Full rules (castling, en passant, promotion, repetition, fifty-move rule) on a perft-verified 0x88 move generator, against a negamax bot with five levels.
